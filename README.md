# Decision Tree

This repository contains my Machine Learning practice projects using Decision Tree algorithms. It covers both classification and regression problems using Python and Scikit-learn.

## 📁 Project Structure

### 1. Classifier
This folder contains my **Decision Tree Classification** projects.

Topics covered:
- Data preprocessing and cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Encoding categorical variables
- Train-test splitting
- Building Decision Tree Classifier models
- Hyperparameter tuning using Cross-Validation
- Model evaluation using Accuracy, Precision, Recall, and F1 Score
- Decision Tree visualization
- Saving and loading trained models using Pickle

### 2. Regression
This folder contains my **Decision Tree Regression** projects.

Topics covered:
- Data preprocessing and cleaning
- Handling missing values and outliers
- Feature engineering
- Date and time feature extraction
- Latitude and longitude processing
- Calculating geographical distance using the Haversine formula
- Building Decision Tree Regressor models
- Hyperparameter tuning using Cross-Validation
- Understanding overfitting and underfitting
- Model evaluation using MAE, MSE, RMSE, and R² Score

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle
- Jupyter Notebook

## 🎯 Objective

The main objective of this repository is to understand and implement Decision Tree algorithms for both classification and regression problems through practical projects.

This repository represents my Machine Learning learning journey, with a focus on data preprocessing, feature engineering, model training, evaluation, and optimization.
